GLOW Skin Intelligence™

«Search Less. Glow More.»

A premium skincare landing page concept that reimagines Google as a modern skincare brand. The project combines a search-inspired user experience with a clean, editorial skincare aesthetic to create a product-focused landing page designed around discovery, trust, and conversion.

✨ Concept

The idea was to take Google's most recognizable interaction — search — and reinterpret it as a skincare experience.

Instead of searching the web, users can "search their skin" and discover a recommended product match.

The visual direction intentionally keeps Google's influence subtle while making GLOW feel like an independent premium skincare brand.

🎯 Key Features

- Premium responsive landing page
- Google-inspired skincare reimagination
- Interactive skin-search experience
- Animated search result reveal
- Product-focused hero section
- Primary and secondary CTA hierarchy
- Ingredient / formula showcase
- Social proof and testimonials
- Product purchase section
- Interactive FAQ
- Responsive navigation
- Mobile, tablet, and desktop layouts
- Subtle micro-interactions and animations
- Accessible text contrast and semantic HTML

🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- SVG
- Vercel

🎨 Design Direction

The design combines:

Luxury Skincare × Search Experience × Modern Technology

The visual system uses a warm ivory background, premium gold accents, near-black typography, soft shadows, rounded interfaces, glass-like product visuals, and carefully controlled Google-inspired color accents.

The goal was to keep the interface minimal and premium rather than making it look like a direct copy of Google's website.
